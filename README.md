 Description
ProfileListApp is a simple Android app with one screen (MainActivity).
Users enter a Name and Age, then tap Add Profile to store profiles in a list and display them in a TextView using a for loop.

 Features
- One-screen app (MainActivity)
- Inputs: Name and Age
- Button: Add Profile
- Displays all profiles in format: `Name – Age`
- Logs Android lifecycle methods:
  - onCreate, onStart, onResume, onPause, onStop, onDestroy
